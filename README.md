# 🚀 EJERCICIOS DE FUNDAMENTOS EN JAVASCRIPT

Este repositorio contiene una colección de scripts en JavaScript que muestran el uso práctico de estructuras de control de flujo, condicionales y bucles.

---

## 🛠️ CONTENIDO DEL CÓDIGO

El script principal se divide en 4 partes fundamentales:

1. **Evaluador de notas (`if / else if / else`):** Clasifica la nota de un estudiante (Suspenso, Aprobado, Notable, Sobresaliente).
2. **Día de la semana (`switch`):** Muestra el nombre del día según su código numérico del 1 al 7.
3. **Resumen del grupo (`for...of`):** Recorre un array de notas y cuenta el total de aprobados y suspensos.
4. **Revisiones pendientes (`do...while`):** Procesa una serie de revisiones de forma iterativa hasta completarlas todas.
